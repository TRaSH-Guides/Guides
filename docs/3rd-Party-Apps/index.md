# Third-Party Apps & Guides

!!! info
    This page only includes guides that follow the Guide guidelines, and apps that are somewhat related to what this guide covers and stands for. [Third-party Guide Sync Tools](/Guide-Sync/) are only listed here if they are approved and officially supported.

    If you have a suggestion or recommendation, or want to request that an app or guide be added, join our [Discord server](/discord) and post your request in #suggestions.

---

## Recommended 3rd-Party Apps & Scripts

| Apps & Scripts | Description |
| --- | --- |
| **[autobrr](https://autobrr.com/)** [:fontawesome-solid-globe:](https://autobrr.com/ "Website") [:fontawesome-brands-github:](https://github.com/autobrr/autobrr "GitHub") [:fontawesome-brands-discord:](https://discord.gg/WQ2eUycxyT "Discord") | Modern download automation for torrents and Usenet. Watches IRC announcements and RSS/Torznab feeds, then sends matches to your download client the moment they are posted. |
| **[Bazarr](https://www.bazarr.media/)** [:fontawesome-solid-globe:](https://www.bazarr.media/ "Website") [:fontawesome-brands-github:](https://github.com/morpheus65535/bazarr "GitHub") [:fontawesome-brands-discord:](https://wiki.bazarr.media/discord "Discord") | Companion application to Radarr and Sonarr that finds and downloads subtitles for your library automatically. |
| **[BZ qui Workflows](https://github.com/BZ00001/qui_workflows)** [:fontawesome-brands-github:](https://github.com/BZ00001/qui_workflows "GitHub") [:fontawesome-brands-discord:](/discord "Discord") | Community qui automation rule set for qBittorrent. The base workflow that TRaSH qui Workflows builds on. |
| **[BZ Scripts](https://github.com/BZ00001/scripts)** [:fontawesome-brands-github:](https://github.com/BZ00001/scripts "GitHub") [:fontawesome-brands-discord:](/discord "Discord") | Standalone Python scripts for Radarr, Sonarr, Plex, and Kometa maintenance, covering tag-based upgrade searches, file renaming, and orphaned Kometa asset cleanup. |
| **[clonarr](https://github.com/ProphetSe7en/clonarr)** [:fontawesome-brands-github:](https://github.com/ProphetSe7en/clonarr "GitHub") [:fontawesome-brands-discord:](/discord "Discord") | GUI-based TRaSH Guides sync tool. Free and self-hosted. Build profiles from scratch or start with TRaSH Guides templates, compare your Arr profiles to TRaSH Guides to identify missing or incorrect items, test how releases score in the Scoring Sandbox, and track all changes with sync history and rollback, as one of the officially supported Guide Sync Tools. |
| **[cross-seed](https://www.cross-seed.org/)** [:fontawesome-solid-globe:](https://www.cross-seed.org/ "Website") [:fontawesome-brands-github:](https://github.com/cross-seed/cross-seed "GitHub") [:fontawesome-brands-discord:](https://discord.com/invite/jpbUFzS5Wb "Discord") | Automatically finds and cross-seeds matching torrents across trackers, so a single download can seed on every tracker that has it. |
| **[Kometa](https://kometa.wiki/)** [:fontawesome-solid-globe:](https://kometa.wiki/ "Website") [:fontawesome-brands-github:](https://github.com/Kometa-Team/Kometa "GitHub") [:fontawesome-brands-discord:](https://kometa.wiki/en/latest/discord/ "Discord") | Adds and manages Plex metadata, collections, and overlays, formerly known as Plex Meta Manager. Can use the guide's naming scheme to build overlays such as edition tags. |
| **[Maintainerr](https://maintainerr.info/)** [:fontawesome-solid-globe:](https://maintainerr.info/ "Website") [:fontawesome-brands-github:](https://github.com/Maintainerr/Maintainerr "GitHub") [:fontawesome-brands-discord:](https://discord.maintainerr.info "Discord") | Library maintenance tool for Plex, Jellyfin, and Emby. Groups stale or unwanted media into rule-based collections and can delete files, unmonitor items in Radarr and Sonarr, or clear requests in Seerr. |
| **[Notifiarr](https://notifiarr.com/)** [:fontawesome-solid-globe:](https://notifiarr.com/ "Website") [:fontawesome-brands-github:](https://github.com/Notifiarr/notifiarr "GitHub") [:fontawesome-brands-discord:](https://discord.com/invite/AURf8Yz "Discord") | Brings notifications from your media stack into Discord, and can sync TRaSH Guide profiles to Radarr and Sonarr as one of the officially supported Guide Sync Tools. |
| **[PosterFlow](https://github.com/dweagle/posterflow)** [:fontawesome-brands-github:](https://github.com/dweagle/posterflow "GitHub") [:fontawesome-solid-book:](https://github.com/dweagle/posterflow/wiki "Wiki") [:fontawesome-brands-discord:](https://discord.gg/3EyfQAxpTq "Discord") | Self-hosted poster manager that syncs posters from community and custom Google Drive sources, renames them to match your Plex, Radarr, and Sonarr library, and uploads them directly to Plex or a Kometa assets folder. |
| **[qbit_manage](https://github.com/StuffAnThings/qbit_manage)** [:fontawesome-brands-github:](https://github.com/StuffAnThings/qbit_manage "GitHub") | Automates tedious qBittorrent maintenance: tagging, categorizing, removing orphaned data, removing unregistered torrents, and applying share limits. |
| **[qui](https://getqui.com)** [:fontawesome-solid-globe:](https://getqui.com "Website") [:fontawesome-brands-github:](https://github.com/autobrr/qui "GitHub") [:fontawesome-brands-discord:](https://discord.gg/WQ2eUycxyT "Discord") | Fast, single-binary qBittorrent web UI. Manages multiple qBittorrent instances, automates torrent workflows, and includes native cross-seed support. |
| **[qui-sync](https://github.com/ProphetSe7en/qui-sync)** [:fontawesome-brands-github:](https://github.com/ProphetSe7en/qui-sync "GitHub") [:fontawesome-brands-discord:](/discord "Discord") | Web UI for managing qui automation rules as code. Publishes rules to a git repo, subscribes to shared repos, and backs up or restores qui automations. |
| **[Recyclarr](https://recyclarr.dev/)** [:fontawesome-solid-globe:](https://recyclarr.dev/ "Website") [:fontawesome-brands-github:](https://github.com/recyclarr/recyclarr "GitHub") [:fontawesome-brands-discord:](/discord "Discord") | Command-line tool that automatically syncs recommended settings from TRaSH Guides. Free and self-hosted, as one of the officially supported Guide Sync Tools. |
| **[resolvarr](https://github.com/ProphetSe7en/resolvarr)** [:fontawesome-brands-github:](https://github.com/ProphetSe7en/resolvarr "GitHub") [:fontawesome-brands-discord:](/discord "Discord") | Helper container for Radarr and Sonarr. Tags releases by group, recovers missing release groups from grab history, tags audio and video info, and mirrors tags between instances. |
| **[seasonpackarr](https://github.com/nuxencs/seasonpackarr)** [:fontawesome-brands-github:](https://github.com/nuxencs/seasonpackarr "GitHub") | Companion app for autobrr that hardlinks already-downloaded episodes into a season folder when a season pack is announced, so episodes do not need to be re-downloaded. |
| **[Seerr](https://seerr.dev/)** [:fontawesome-solid-globe:](https://seerr.dev/ "Website") [:fontawesome-brands-github:](https://github.com/seerr-team/seerr "GitHub") [:fontawesome-brands-discord:](https://discord.gg/seerr "Discord") | Open-source media request and discovery manager for Jellyfin, Plex, and Emby, the unified successor to Overseerr and Jellyseerr. |
| **[Tautulli](https://tautulli.com/)** [:fontawesome-solid-globe:](https://tautulli.com/ "Website") [:fontawesome-brands-github:](https://github.com/Tautulli/Tautulli "GitHub") [:fontawesome-brands-discord:](https://tautulli.com/discord "Discord") | Monitoring and tracking tool for Plex Media Server, showing watch history, statistics, and notifications for stream activity. |
| **[Tracearr](https://tracearr.com/)** [:fontawesome-solid-globe:](https://tracearr.com/ "Website") [:fontawesome-brands-github:](https://github.com/connorgallopo/Tracearr "GitHub") | Real-time monitoring for Plex, Jellyfin, and Emby, tracking streams, analyzing playback, and detecting account sharing from a single dashboard. |
| **[TRaSH qui Workflows](https://github.com/TRaSH-/qui_workflows)** [:fontawesome-brands-github:](https://github.com/TRaSH-/qui_workflows "GitHub") [:fontawesome-brands-discord:](/discord "Discord") | TRaSH's own tier-based qui automation rule set for qBittorrent, based on the BZ workflow with adjusted noHL seeding time and optional pre-information tags. |
| **[Unpackerr](https://unpackerr.zip)** [:fontawesome-solid-globe:](https://unpackerr.zip "Website") [:fontawesome-brands-github:](https://github.com/Unpackerr/unpackerr "GitHub") [:fontawesome-brands-discord:](https://golift.io/discord "Discord") | Extracts downloaded archives for Radarr, Sonarr, Lidarr, and other *arr apps, then deletes them after import, so compressed releases do not need to be unpacked by hand. |
