# Sonarr - Custom Format Groups

Custom Format Groups are logical groupings of custom formats used by sync tools such as [Recyclarr](https://recyclarr.dev) and [Notifiarr](https://notifiarr.com). Each group bundles related custom formats together for easier profile management and/or display.

::: info

Custom Format Groups are metadata used by external sync tools and are shown here for reference only. They are **not** designed to be imported into Sonarr and cannot be used directly within the application.

:::
